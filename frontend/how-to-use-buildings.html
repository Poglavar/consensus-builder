Learn by doing

Draw a building, or define a rule

Use freeform for an exact footprint. Use a block, row or detached-house rule to describe what can or must be built on the selected land.

Design a house by hand

  1. Start a freeform building

    Select a parcel or site, open Propose and choose Freeform building. Confirm whether to use the selected parcel or its surrounding block. The editor opens directly on the map with footprint handles, height and site controls.

  2. Shape the footprint on the map

    Drag the building to move it. Drag a vertex to reshape it; click an edge to add a vertex. Select a vertex and use the trash control or Delete / Backspace to remove it. Rotate the footprint in 5° steps. Keep the footprint within the site.

  3. Set height and surroundings

    Adjust Height and inspect the footprint and geometry statistics. Site & details contains further settings where available. Finish with Done, then switch to 3D to compare the proposed building with its surroundings.

  4. Read the geometry statistics

    The card reports parcel area, building footprint, site coverage (kig), above-ground gross floor area (GBP) and kin. These are calculated from the drawn geometry and height, with a 3 m storey assumption. Finish with Done and inspect the proposal on the map.

What the rule compels

What the rule compels separates a building requirement from a building limit. The controls are shared by Block, Row houses and Detached houses.

Rule Meaning
At most this Sets a ceiling. Owners do not have to build the full envelope.
Between a minimum and this Requires a minimum and permits development up to the ceiling.
Exactly this Requires the full specified envelope.

Minimum plot size excludes smaller plots; they are shown hatched and need to be merged before building under that rule. A preview is an example of what could be built, so check the permitted and guaranteed figures as well as the shapes.

Block and existing buildings

Block opens Urban rule . Set the setback, wing depth ( Building width ), height, chamfer and outline simplification. Reduce the depth if the courtyard disappears. Where gap and wing controls are enabled, drag their handles along the perimeter.

Use Edit shape manually to drag outline vertices, add points on edges or delete a selected point. Back to sliders discards the manual outline after confirmation. Upload GeoJSON imports a polygon. A range rule also exposes minimum height and the required building depth from the street.

Based on existing buildings uses the existing footprints instead of drawing a new block. Choose a proposed height in floors or additional floors and set floor height. This mode needs building data for the selected land.

Row houses

Select at least two contiguous parcels and choose Row houses. Length, width, height and chamfer define the initial row. Drag the footprint to move it, drag vertices to reshape it, click an edge to add a vertex, or delete a selected vertex. Use the 5° rotation controls or import GeoJSON.

The footprint must fit the selected land. Set the height rule and minimum plot size, then inspect the generated houses in the preview. Differently sized parcels can produce a warning; review the result before finishing.

Detached houses and parcel rules

The Detached houses tool applies a rule separately to each selected parcel. Set maximum floors, minimum distance from borders and minimum plot size. A range rule adds minimum floors and minimum ground-floor area; an exact rule uses the full permitted envelope.

Regenerate creates another example with different floor counts, footprint sizes and positions. It does not change the permitted footprint or volume. Check hatched plots: they may be too small, have no room after setbacks, or be unable to meet the minimum.

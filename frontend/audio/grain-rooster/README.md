# Recorded rooster cues

Both cues are excerpts from a real Black Jersey Giant rooster recording by **jsbarrett**, released
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/):
[Rooster clucking, Freesound #200335](https://freesound.org/people/jsbarrett/sounds/200335/).

| File | Use | Source excerpt |
| --- | --- | --- |
| `rooster-check-fail.wav` | One short cluck when a parcel is too large | 11.105–11.225 s |
| `rooster-check-success.wav` | The natural happy call when a parcel is eaten | 8.180–8.650 s |

The files are mono 44.1 kHz, 16-bit PCM WAV. The success cue is one uninterrupted excerpt: it was
cut at the nearest zero crossings without pitch shifting, synthesis, splicing, filtering or added
effects.

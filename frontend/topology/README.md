# Topology workbench moved

As of 2026-10-15, the active workbench, junction recognition and processors live in the private `zagreb-promet-topologija` repository. Open the sibling [repository and setup instructions](../../../zagreb-promet-topologija/README.md) for further work.

See the root [agent instructions](../../AGENTS.md#topology-migration-2026-10-15) for ownership of the simulator, public endpoints and shared table definitions. Generic proposal/corridor editing remains in Consensus Builder.

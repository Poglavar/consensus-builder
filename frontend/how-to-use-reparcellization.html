Learn by doing

Choose a starting layout

Select contiguous parcels or draw a site and choose Land readjustment . The map previews the resulting plots; New plots and Old plots switch the right-hand list between outputs and inputs. The original cadastre remains the reference.

Automatic

Start with Equal plots and set Number of plots. Schelling plots offers another layout; Keep existing borders preserves the starting pattern, while Draw freely starts a manual layout. Drag nodes or boundary segments to reshape the divisions. Compare New plots and Old plots before choosing Done.

Draw freely

Draw freely starts with the undivided site. Draw plot places a polygon; click its vertices and finish it. Draw a line cuts existing plots. Erase a boundary merges neighbours, while Edit boundaries (nodes) lets you move the dividing geometry. Use Undo to reverse an edit or Upload GeoJSON to import a layout.

The layout editor checks the geometry and site coverage. Review ownership allocations in an agreement for the applied designs.

Keep existing parcels and shared courtyards

Keep existing parcels starts from the original plots and owners. Use nodes, cuts and boundary removal for targeted changes. This option is unavailable for a drawn site pool that has no existing plot layout to retain.

For a Shared courtyard , choose From a building block to use an overlapping block’s courtyard, or Draw on map . The courtyard is jointly owned. Initial shares follow the owners’ remaining private land; Edit shares sets fixed percentages, which must total 100%.

Owners, shares and cash

Lay out parcels defines geometry. To coordinate ownership and money, create an agreement from the applied designs. Review the input land, resulting pieces, owner allocations, terms and decision rule there. A geometric layout alone does not record owner consent or transfer title.

The ledger separates contributed value, assigned value, balance and cash. Cash uses one sign convention: positive means the owner receives money; negative means the owner pays. Review the net amount for the whole design as well as each owner’s amount. The proposer funds any shortfall between owner payments and compensation, or receives the surplus. Cash figures in this ledger are EUR. Contributed and assigned values are estimates, not money paid: a source price needs an explicit currency, and the EUR 100/m² fallback applies only when no source price is present. Geometry, shares and cash all need to be valid before finishing.

A shared courtyard can use one agreement or separate parcel agreements. Separate agreements keep each private remainder with its original owners and contribute that parcel’s part of the courtyard. Review each agreement before publishing; retry remaining agreements if only some were created.

Finish the layout

Done saves the valid layout and completes the direct design flow. When working inside a design form, it saves the layout into that design; submit the form to finish. Cancel or closing the designer discards the session after confirmation when needed. Open the finished design to inspect, fork, share or unapply it.

Changing plot geometry can unapply designs that stand on those plots. Review the affected-designs message before confirming; unchanged plots keep their designs.

Learn by doing

Change the plots. Review every owner.

Choose a parcel layout, edit boundaries and compare old and new plots. Review ownership and money separately in an agreement.

Choose a starting layout

Select contiguous parcels or draw a site and choose Land readjustment . The map previews the resulting plots; New plots and Old plots switch the right-hand list between outputs and inputs. The original cadastre remains the reference.

Automatic

Start with Equal plots and set Number of plots. Schelling plots offers another layout; Keep existing borders preserves the starting pattern, while Draw freely starts a manual layout. Drag nodes or boundary segments to reshape the divisions. Compare New plots and Old plots before choosing Done.

Draw freely

Draw freely starts with the undivided site. Draw plot places a polygon; click its vertices and finish it. Draw a line cuts existing plots. Erase a boundary merges neighbours, while Edit boundaries (nodes) lets you move the dividing geometry. Use Undo to reverse an edit or Upload GeoJSON to import a layout.

The layout editor checks the geometry and site coverage. Review ownership allocations in an agreement for the applied designs.

Keep existing borders and carve a courtyard

Keep existing borders begins with the original plot pattern. Use nodes, cuts and boundary removal to adjust it. Courtyard carves the inner courtyard of a planned building block as a plot of its own.

Choose that plot’s single recipient in the plan’s agreement. Different recipients need separate plots; the layout editor does not assign joint ownership.

Owners, allocations and compensation

Finish the layout, then open Plans and create a named plan containing it. Open that plan and choose Create agreement. Agreements select an existing plan; they do not select or change its designs.

The agreement editor has four tabs. Input parcels selects the plan and lists its input land and designs. Each input parcel is one party, “Owner(s) of parcel X”; with ownership rights loaded, its owners and shares are shown beside it. Output parcels assigns each resulting parcel to one parcel party, the proposer or Public. Persons works out each owner's land and cash from those shares.

Rules sets the decision scheme, compensation rate per m² and any land contribution permitted by that scheme. Monetary compensation is calculated from each party’s remaining land entitlement and allocated area: a shortfall receives money; an excess pays. The sponsor pays or receives the difference. Currency is the city’s stated fiat currency, EUR here. Parcel ownership rights and lens operations open their own dialogs.

Persons is a read-only tally of each person’s land and money in and out. Zero cash is omitted from the person rows. Input and output land and the calculated cash schedule must balance before saving. Use Save agreement for local work, then Propose when ready to publish.

Finish the layout

Done saves the valid layout and completes the direct design flow. When working inside a design form, it saves the layout into that design; submit the form to finish. Cancel or closing the designer discards the session after confirmation when needed. Open the finished design to inspect, fork, share or unapply it.

Changing plot geometry can unapply designs that stand on those plots. Review the affected-designs message before confirming; unchanged plots keep their designs.

Learn by doing

Change the plots. Review every owner.

Choose automatic divisions, draw a layout yourself or preserve existing parcels. Check the resulting land, ownership shares and cash together.

Choose a starting layout

Select contiguous parcels or draw a site and choose Land readjustment . The map previews the resulting plots; New plots and Old plots switch the right-hand list between outputs and inputs. The original cadastre remains the reference.

Mode Starting point
Automatic Parallel divisions through the pooled land. Rotate the split direction.
Draw freely An undivided site. Draw plots and split them yourself.

Automatic

Start with Automatic and drag the direction handle on the map to rotate the divisions. For a single-owner selection, set Number of parcels and choose Equal, Random or Manual distribution. Check both the new plot areas and the owner allocation.

Draw freely

Draw freely starts with the undivided site. Draw plot places a polygon; click its vertices and finish it. Draw a line cuts existing plots. Erase a boundary merges neighbours, while Edit boundaries (nodes) lets you move the dividing geometry. Use Undo to reverse an edit or Upload GeoJSON to import a layout.

Assign owners to every plot. The editor checks coverage, overlaps and owner shares before allowing Done.

Keep existing parcels and shared courtyards

Keep existing parcels starts from the original plots and owners. Use nodes, cuts and boundary removal for targeted changes. This option is unavailable for a drawn site pool that has no existing plot layout to retain.

For a Shared courtyard , choose From a building block to use an overlapping block’s courtyard, or Draw on map . The courtyard is jointly owned. Initial shares follow the owners’ remaining private land; Edit shares sets fixed percentages, which must total 100%.

Owners, shares and cash

Use Review one owner to inspect the input land, assigned land and net change for that owner. Before / after overlays the two states with a draggable divider. Dashed amber outlines mark input parcels; solid blue outlines show assigned plots.

The ledger separates contributed value, assigned value, balance and cash. Cash uses one sign convention: positive means the owner receives money; negative means the owner pays. Review the net amount for the whole proposal as well as each owner’s amount. The proposer funds any shortfall between owner payments and compensation, or receives the surplus. Geometry, shares and cash all need to be valid before finishing.

A shared courtyard can use one agreement or separate parcel agreements. Separate agreements keep each private remainder with its original owners and contribute that parcel’s part of the courtyard. Review each agreement before publishing; retry remaining agreements if only some were created.

Finish the layout

Done saves the valid layout and completes the direct design flow. When working inside a proposal form, it saves the layout into that proposal; submit the form to finish. Cancel or closing the designer discards the session after confirmation when needed. Open the finished proposal to inspect, fork, share or unapply it.

Changing plot geometry can unapply designs that stand on those plots. Review the affected-proposals message before confirming; unchanged plots keep their designs.

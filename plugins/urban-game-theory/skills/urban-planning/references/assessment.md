# Assessing a plan

Select indicators that answer the user's decision and can be supported by the available data. Do not fill every category merely to make a table look complete.

| Dimension | Examples, only where supported |
| --- | --- |
| Capacity and land use | Site area, proposed floor area, use mix, dwelling estimate, jobs estimate |
| Built form | Footprint coverage, heights, setbacks, block dimensions and relationship to surroundings |
| Movement | Street connections, accessible pedestrian routes, cycle/transit connections, servicing and parking |
| Public space and environment | Public/open-space area, access, landscape, drainage, relevant known hazards |
| Community outcomes | Access to facilities, proposed affordability commitments, potential displacement pressures, impacts on different groups |
| Delivery | Phases, dependencies, infrastructure requirements, land assembly and explicitly assumed costs |

## Definitions and checks

- State whether the site area is gross or net and which land is included. Use the same denominator across compared options.
- FAR/FSI is the included floor area divided by the relevant site area. Local definitions of counted floors and exclusions can differ; use a verified definition or label the calculation as a conceptual ratio.
- Coverage is the relevant building footprint area divided by the site area. Avoid double-counting overlapping footprints and identify retained versus new development.
- Density in dwellings/hectare requires a defined dwelling count and area basis. State gross/net and existing/proposed/total. If deriving units from floor area, give the assumed unit size and efficiency factor; do not present that estimate as a measured count.
- Report metres, square metres, hectares, and percentages explicitly; 1 hectare = 10,000 square metres. Convert only from known source units.
- Distinguish network-based journey estimates from straight-line distance. Explain assumed mode and speed when estimates depend on them.
- Do not infer affordability, tenure, cost, carbon, flooding, daylight, or legal compliance from a footprint alone. Use relevant evidence or identify the missing analysis.
- Treat an absent value as unknown, not zero. If a tool output conflicts with other evidence, investigate and state the unresolved discrepancy.

## Comparison format

Use columns for the baseline and each option, with rows for a small set of relevant measures. Add a method/source column when useful. Include a short account of who benefits, who bears costs, and what has not been tested. Keep observations separate from value judgments. If weighted scoring is requested, state the criteria, weights, normalization method, and sensitivity to those choices.

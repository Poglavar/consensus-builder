# Rekonstrukcije

`rekonstrukcije/` holds former or existing plans and built projects reconstructed as proposals in the app. These are reference reconstructions of real urban form, not proposals for future development merely because they use the proposal data model.

Each reconstruction should keep, where available:

- a README describing scope, dates, sources, provenance and known uncertainty;
- source and normalized GeoJSON;
- reproducible extraction, conversion, import or upload scripts;
- stable proposal identifiers or a link to the corresponding records in the system.

Standalone plans live directly below this directory, such as [`upu-borovje/`](upu-borovje/). Collections organized around one developer or research series may have an intermediate folder, such as [`pionir-paron/`](pionir-paron/).

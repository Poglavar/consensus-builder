# Folnegovićeva–Rapska

Observed-state reconstruction of three completed buildings on k.č. 2708/1, k.o. Trnje. [`proposal.geojson`](proposal.geojson) uses current DGU legal footprints and matched GDI 2022 heights. It is stored locally as unapplied proposal row 1084 and passes the canonical proposal GeoJSON round trip.

The derived GBP is a diagnostic `footprint × height / 3 m` estimate, not permit-stated GBP.

# Folnegovićeva–Rapska

Observed-state reconstruction of three completed buildings on k.č. 2708/1, k.o. Trnje. [`proposal.geojson`](proposal.geojson) uses current DGU legal footprints and matched GDI 2022 heights. It is stored locally as unapplied proposal row 1084 and passes the canonical proposal GeoJSON round trip.

The derived GBP is a diagnostic `footprint × height / 3 m` estimate, not permit-stated GBP.

## Internal circulation

[`circulation-access-241116394.geojson`](circulation-access-241116394.geojson) reconstructs the connected 402 m internal service/parking-aisle network from five current OSM ways. No defensible parking-area polygon exists inside the site, so the parking aisles are represented as access surface only and no individual spaces are invented. [`plan.json`](plan.json) groups the road with the building proposal as named local plan `pionir-folnegoviceva-rapska`.

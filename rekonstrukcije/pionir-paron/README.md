# Pionir / Paron

This folder collects large Pionir/Paron developments with more than two buildings. Each project should ultimately include the site and building footprints as GeoJSON, parcel and permit provenance, dates and a reproducible proposal import or construction path.

| Project | Current reconstruction | Canonical material |
|---|---|---|

The broader project inventory—name, construction dates, location, site area and building count—belongs here as candidates are verified. A project folder should distinguish observed built footprints from permit-derived planned footprints instead of silently mixing the two.

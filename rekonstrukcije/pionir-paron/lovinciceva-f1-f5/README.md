# Lovinčićeva F1–F5

Observed-state reconstruction of five completed buildings on k.č. 4091/5, k.o. Peščenica. [`proposal.geojson`](proposal.geojson) uses current DGU legal footprints and matched GDI 2022 heights. It is stored locally as unapplied proposal row 1085 and passes the canonical proposal GeoJSON round trip.

The F1–F5 labels have not yet been safely assigned to individual DGU polygons. The derived GBP is a diagnostic `footprint × height / 3 m` estimate, not permit-stated GBP.
